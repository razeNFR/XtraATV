# XtraPlus 1.4.9.2

### New Features
- **TV Chat Scrolling**: Scroll through previous chat messages with the remote control from the TV Chat panel or via a customizable remote shortcut. Auto-scroll pauses while reading older messages and resumes when returning to the latest message or exiting.
- **More Proxy Protocols (HTTP, HTTPS, SOCKS4 & SOCKS5)**: Stream proxies now support `https://`, `socks5://` / `socks://`, and `socks4://` in addition to HTTP — making self-hosted and VPN-provided proxies (such as Mullvad) easy to configure.
- **Optional Stream Language Badge**: Display a discreet language code badge (`EN`, `FR`, `DE`, …) on stream thumbnails (off by default — enable in *Interface → Customization* on TV or *Settings → Interface* on Mobile).

### Improvements & Fixes
- **Clearer Adblock Descriptions (TV & Mobile)**: Removed the "Experimental" label from **Swap+** and **VOD**, clarified that **Swap** drops to 360p during ads and supports **1440p** (along with **VOD**), and noted that **Swap+** is limited to **1080p** (and uses Swap in Multi-Stream & PiP on TV).
- **TV Voice Input Focus**: After dictating a chat message with the microphone, focus now moves automatically to the **Send** button so pressing OK sends the message instead of re-recording.
- **Fire TV On-Screen Keyboard**: Pressing Next, Done, or Back on the Fire TV keyboard now closes the keyboard and preserves your draft instead of auto-sending the message.
- **TV Proxy Settings Navigation**: Fixed D-pad navigation in the Proxy settings screen so you can move down from **+ Add** to edit or toggle existing proxies.
- **Mobile UI Settings Restored**: Restored the **Show tags** toggle and other classic display toggles under *Settings → Interface* on Mobile (kept cleanly hidden on Android TV).
