# Xtra TV 1.3.9

### New features & improvements
- **Ad blocker (Experimental)**: new optional mode in *Ads & Proxies* offering uninterrupted playback without quality drops (with a slight ~30s stream and auto-chat offset) across the player, Multi-Stream, and Picture-in-Picture, with automatic fallback to **Ad blocker (Swap)** when unavailable.
- **Refined Ads & Proxies settings**: renamed the default blocker to **Ad blocker (Swap)**, added automatic mutual exclusion with custom/HTTP proxies, and moved **Video swap settings** to **Advanced**.

### Install
Download `XtraTV-1.3.9-tv.apk` below and install it over the previous version, your settings and account are kept.
