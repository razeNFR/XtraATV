# Xtra TV 1.4.6.3

### New & Polish
- **Universal `Back (long press)` & remote long-press compatibility (`#88`)**: disabled predictive `OnBackInvokedCallback` interception on Android 13/14+ TV firmware (`targetSdk 37`) and added a `ViewConfiguration` long-press timer + hold-duration fallback across `Back`, D-pad, and custom remote shortcuts so remotes and Android TV boxes that do not emit auto-repeat events while holding a button (such as Ugoos AM8, Amlogic RF/IR, and HDMI-CEC remotes) reliably trigger long-press actions while held without affecting short-press navigation or Shield remotes.
- **Refined compact 2-line Player HUD header**: redesigned the top-left player header with a `42dp` ringed circular streamer avatar beside a compact 2-line column — a single capsule row pairing the **Streamer** chip (`Name (login)`) with a unified **Game / Category** capsule (box-art icon + name inside one focusable pill, replacing the text separator), and the stream title cleanly aligned underneath — with dynamic right-side width clamping (`tvTopRightAnchor` + `syncTvHeaderBounds`) guaranteeing zero overlap with the HUD clock, always-on clock, or adblock badge even when side-by-side chat is open.
- ***Last watched stream* remote shortcut**: added **Last watched stream** (*Dernier stream regardé*) to assignable D-pad and custom remote shortcuts so you can instantly toggle (`Stream A ↔ Stream B`) back to your previously watched live stream from full-screen playback, mini-player / audio-only mode, or anywhere in the menus.
- **Global Android TV / Google TV Voice & System Search**: registered `ACTION_SEARCH`, Google Assistant `SEARCH_ACTION`, and `MEDIA_PLAY_FROM_SEARCH` with `@xml/searchable` so system-wide Android TV / Google TV text and voice searches open Xtra's search screen pre-filled with your query (or directly start playback when a matching live streamer is online).
