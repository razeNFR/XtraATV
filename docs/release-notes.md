# Xtra TV 1.2.11

### New
- **Multi-stream sound mix**: Sound in the panel of the multi-stream (OK) plays either the selected stream only, as before, or all the streams at once, each at its own volume (for example 80 % and 20 %). The volumes are kept for the next times.

### Changes
- **Multi-stream, cleaner picture**: the white frame of the selected stream and the names of the streams fade out a few seconds after the last key, and come back as soon as a key is pressed.

### Install
Download `XtraTV-1.2.11-tv.apk` below and install it over the previous version, your settings and account are kept.
